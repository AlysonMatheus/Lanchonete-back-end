# 🍔 Sistema de Lanchonete

> Um sistema completo para gerenciamento de pedidos e cardápio de uma lanchonete, desenvolvido com backend em Spring Boot e frontend em Angular.

---

## 🚀 Tecnologias Utilizadas

### Backend
* **Java 17** 
* **Spring Boot** (Web, DevTools, Data JPA)
* **Banco de Dados:**  PostgreSQL 
* **Maven** (Gerenciador de dependências)

### Frontend
* **Angular 16+**
* **RxJS** e **HttpClient** para consumo da API

---

## 🛠️ Funcionalidades

* 📦 **Gerenciamento de Cardápio:** Cadastro, edição, visualização e exclusão de produtos (lanches, bebidas, sobremesas).
* 🛒 **Fluxo de Pedidos:** Carrinho de compras, seleção de itens e fechamento do pedido.
* 👥 **Clientes:** Cadastro e identificação de clientes para entrega.
* 📊 **Painel do Atendente:** Tela para visualizar os pedidos pendentes e atualizar o status (Em preparo, Pronto, Entregue).
